# Weeks

One folder per week, named by ISO week number (Monday start), for example `2026-W45`.

```
weeks/2026-W45/
  research.md     Researcher findings, with sources
  targeting.md    personas and hooks for this week
  plan.md         7-day plan with status line (from templates/week/plan.md)
  content/        final posts: mon-01-reel, tue-01-carousel, ...
  report.md       performance and lessons (written by the Analyst)
```

Plan status: `draft → approved → content-ready → posted`. No content is created before `approved`.
