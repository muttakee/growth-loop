# Brand assets

Put the brand's media files here. `/setup-business` asks for them.

- `logo.png`: main logo. PNG with a transparent background, at least 1000px wide.
- `photo.png`: **personal profiles only.** A clear photo of the person (ideally a cut-out with a
  transparent background). It's placed in a corner of every post design.

If a file is in another format (e.g. `logo.jpg`), keep its extension and update the path in `brief.md`.
Templates for images, carousels and reels read these files from this folder.
